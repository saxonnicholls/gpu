Detailed Description

Work queued on a context's stream, captured once as a CUDA graph and launched again as a whole: one launch in place of each of its kernels and products.

A training step is thousands of small launches; their overhead and the gaps between them are a large part of a step. capture runs a function that queues work on the context's stream (cuda_ops.hpp's steps, products over device memory) without executing it, and launch replays exactly that work: the same kernels on the same device addresses with the same arguments. So whatever changes between replays (a micro-batch's tokens, the learning rate) must live in device memory the captured work reads, written before each launch (device_buffer::upload into the same buffer).

The captured function must not allocate, free, wait for the stream or read device memory on the host: CUDA refuses such a call during capture (the capture mode is thread-local), and capture returns the failure. Run the work once uncaptured first, so that every buffer it grows (cuda_kernels::scratch) has its size. A replay gives the bits of the uncaptured run: it is the same work.

// The device product captured once as a CUDA graph and replayed: new inputs go into the same buffers first
const auto product = [&] {
(void)la::gemm(device, 1.0f, la::matrix_view<const float, right>(dx.span().data(), {n, d}),
la::transposed(la::matrix_view<const float, right>(dw.span().data(), {out, d})), 0.0f,
la::matrix_view<float, right>(dy.span().data(), {n, out}));
};
auto captured = gpu::cuda_graph::capture(*context, product);
if (captured.is_err()) {
std::printf("cuda demo: FAILED - the capture failed with CUDA code %d\n", captured.unwrap_err().code);
return 1;
}
const auto graph = std::move(captured).unwrap();
dy.upload(std::vector<float>(n * out, 0.0f));
graph.launch(); // queued on the context's stream, as the product itself would be
std::vector<float> replayed(n * out);
dy.download(replayed);

Guarantees. Movable, not copyable; owns the graph and its executable. launch is queued on the context's stream and ordered with everything else on it. The context must outlive the graph.

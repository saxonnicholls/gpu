Detailed Description

BitNet's I2_S weights (bitnet.cpp's x86 layout, blocks of 128): rows · cols ternary weights, four a byte, times one scale, over the caller's memory.

Weight j of the row-major tensor is code (packed[j / 128 · 32 + j % 32] >> (6 - 2 · ((j % 128) / 32))) & 3, less 1, times scale (core's ml::i2_s_at, ml/bitnet_kernels.hpp). The scale is a host float, read once with core's ml::i2_s_scale from the tensor's tail, so the packed bytes may live in device memory.

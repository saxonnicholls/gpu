Detailed Description

The snicholls-gpu version, and the core version it was built against.

Overview. The version of this repository, written in three places that scripts/check_version.py keeps equal: the macros below, project(... VERSION) in CMakeLists.txt and the release tag. SNICHOLLS_GPU_REQUIRE_VERSION is the compile-time check for a consumer's header, like core's SNICHOLLS_CORE_REQUIRE_VERSION.

SNICHOLLS_GPU_REQUIRE_VERSION(0, 1, 0); // fails to compile against an older snicholls-gpu
const std::string gpu(snicholls::gpu::version_string());
const std::string core(snicholls::gpu::core_version_string());
std::printf("snicholls-gpu %s, built against snicholls-core %s\n", gpu.c_str(), core.c_str());

Relationships. snicholls::core::version() (core's own); the CMake check snicholls_core_require. Group: snicholls-gpu.

Guarantees. constexpr, noexcept.

Errors. None; SNICHOLLS_GPU_REQUIRE_VERSION is a static_assert.

Performance. Compile time only.

Tests and demos. tests/version_test.cpp, demos/version_demo.cpp.

Dependencies. <string_view>, <snicholls/core/version.hpp>.

Known issues. None.

Status. Experimental, pre-1.0.

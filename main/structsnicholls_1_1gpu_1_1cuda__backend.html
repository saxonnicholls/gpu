Detailed Description

The linalg::blas_backend on a cuda_context: gemm and gemv on the device, the rest on the host.

Trivially copyable (a pointer and the choice of cuda_math); pass it by value. float and double products run on the device, over device memory in place or host memory staged; any other scalar type, and the four host operations, on the host. math = cuda_math::tf32 puts the float products on the tensor cores.
